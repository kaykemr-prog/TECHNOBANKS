# TECHNOBANKS

Sistema em ASP.NET Core MVC para cadastro de solicitações de reparos e novos semáforos inteligentes.

## Tecnologias
- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework Core

## Como executar

```bash
dotnet restore
dotnet run
```

## Banco de Dados

Criar o banco:

```sql
CREATE DATABASE TECHNOBANKS;
```
